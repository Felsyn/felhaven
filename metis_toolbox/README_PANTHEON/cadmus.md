# Cadmus

Decode ESRI shapefile bytes (.shp/.dbf) into geometry and attribute records.

- **UI:** none — format decoder for the Artemis layer stack
- **Brain tool:** none
- **Files:** `tools/cadmus.py`
- **Test:** `python -X utf8 -m unittest tests.test_cadmus`

Details: see the docstring in `tools/cadmus.py`.
