# Hecate

Fetch and cache TIGER/Line roads for an area as tiered Features.

- **UI:** Navigation view → Cartograph (rendered by the Artemis panel)
- **Brain tool:** none
- **Files:** `tools/hecate.py`
- **Test:** `python -X utf8 -m unittest tests.test_hecate`

Details: see the docstring in `tools/hecate.py`.
