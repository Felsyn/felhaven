# Asclepius

Answer Pythia's questions about this computer: vitals, connection and network.
One tool over three readers: Hephaestus (vitals), Aether (online) and Argus
(network). It measures nothing itself.

- **UI:** none
- **Brain tool:** `get_machine_status`
- **Files:** `tools/asclepius.py`
- **Test:** `python -X utf8 -m unittest tests.test_asclepius`

Details: see the docstring in `tools/asclepius.py`.
