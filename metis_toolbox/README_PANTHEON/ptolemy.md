# Ptolemy

Answer Pythia's questions about the sky: the sun, the moon and what is up now.
One tool over three modules: Helios (the sun), Selene (the moon) and Hypatia
(the planets and brightest stars). It computes nothing itself, and needs no
network.

- **UI:** none
- **Brain tool:** `get_sky_report`
- **Files:** `tools/ptolemy.py`
- **Test:** `python -X utf8 -m unittest tests.test_ptolemy`

Details: see the docstring in `tools/ptolemy.py`.
